## The SuperAdmin permission system (final design)
- **Roles:** SuperAdmin = vendor (`HmTech@2023`); Admin = gym owner (`Role=="Admin"` = full access); staff = `Role=="User"` + granular `AppPermission` CSV. `HasPermission` returns true for Role=="Admin".
- **Reserved to SuperAdmin:** POS activation · Online subscription on/off · Suspend (full lock) · Data migration.
- **Two enforcement channels:**
  - **Online gyms → cloud flags.** SuperAdmin portal (`GymDetails`) toggles `IsLocked` / `OnlineEnabled` / `PosEnabled`; the desktop reads them on the lock-status poll and obeys.
  - **Offline gyms → step-up password.** `SuperAdminGate.RequireSuperAdmin` prompts for `HmTech@2023`; the vendor enters it over AnyDesk. The version-label click opens `SuperAdminSettingsDialog` for the POS/online local overrides; data migration prompts inline.
- **Grandfathering:** the 5 existing gyms were UPDATEd to `PosEnabled=TRUE`; new gyms default OFF.
- **Cloud settings (key/URL):** no runtime edit screen (setup wizard / install-time only), so nothing extra to gate; reinstall key-recovery (4.6.18) already protects it.
