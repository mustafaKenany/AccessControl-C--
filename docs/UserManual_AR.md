## 1. نظرة عامة على النظام

AccessControlPro هو نظام شامل لإدارة الصالات الرياضية يتضمن:

- **التطبيق الرئيسي (WPF)** - العمليات اليومية: إدارة اللاعبين، التحكم بالوصول، الأحداث، المالية
- **لوحة الإدارة (Admin)** - إدارة النظام: المستخدمون، المنتجات، الموردون، التقارير، النسخ الاحتياطي
- **نقطة البيع (POS)** - المبيعات: بيع المنتجات، رصيد البطاقات، مسح الباركود

### متطلبات النظام

| المكون | المتطلبات |
|--------|-----------|
| نظام التشغيل | Windows 10 / 11 (64-bit) |
| قاعدة البيانات | SQL Server 2019+ أو SQL Server Express |
| الذاكرة | 4 جيجابايت كحد أدنى |
| التخزين | 500 ميجابايت للتطبيق + قاعدة البيانات |
| .NET Runtime | غير مطلوب (مضمّن ذاتياً) |
| أجهزة التحكم بالوصول | أجهزة تحكم متوافقة مع FK (اختياري) |

### الميزات الرئيسية

- إدارة اشتراكات اللاعبين مع التحكم بالوصول عبر البطاقات
- مراقبة الأجهزة في الوقت الفعلي وتسجيل الأحداث
- تصاريح QR للزوار اليوميين/المؤقتين
- نقطة بيع مع إدارة المخزون
- تتبع مالي (الإيرادات، المصروفات، الأرصدة المستحقة)
- واجهة ثنائية اللغة (العربية / الإنجليزية)
- صلاحيات مستخدمين حسب الدور
- تشفير البيانات وتعزيز الأمان
- دعم الشاشات المتعددة لعرض المدخل

## 2. التثبيت والإعداد

### التثبيت لأول مرة

1. انسخ مجلد **WPF** إلى الحاسب الهدف (مثال: `C:\AccessControlPro`)
2. شغّل ملف `AccessControlPro.WPF.exe`
3. سيظهر **معالج الإعداد** تلقائياً عند التشغيل الأول

### خطوات معالج الإعداد

#### الخطوة 1: الترحيب
- شاشة ترحيب مع معلومات التطبيق
- رفع شعار المطور (اختياري)

#### الخطوة 2: اتصال قاعدة البيانات
- **الخادم**: أدخل اسم خادم SQL Server (مثال: `localhost`، `.\SQLEXPRESS`، أو عنوان IP بعيد)
- **قاعدة البيانات**: اسم قاعدة البيانات (الافتراضي: `AccessControlPro`)
- **المصادقة**: بيانات اعتماد SQL Server (اسم المستخدم + كلمة المرور) أو مصادقة Windows
- انقر **اختبار الاتصال** للتحقق قبل المتابعة

#### الخطوة 3: معلومات الصالة
- **اسم الصالة**: اسم صالتك الرياضية (يظهر في التقارير والإيصالات)
- **العملة**: رمز العملة للعروض المالية (مثال: د.ع، $، يورو)
- رفع شعار الصالة (اختياري، يظهر في التقارير)

#### الخطوة 4: حساب المدير
- **اسم المستخدم**: اسم تسجيل الدخول للمدير
- **كلمة المرور**: يجب أن تستوفي سياسة كلمة المرور (8 أحرف كحد أدنى، أحرف كبيرة وصغيرة، رقم)
- **البريد الإلكتروني**: بريد المدير للاسترداد

#### الخطوة 5: الإنهاء
- مراجعة ملخص الإعدادات
- خيار إنشاء اختصارات سطح المكتب للتطبيقات الثلاثة
- انقر **إنهاء** لإكمال الإعداد

### تثبيت التطبيقات الإضافية

لتثبيت **لوحة الإدارة** و**نقطة البيع**:
1. انسخ مجلدات `Admin` و/أو `POS` إلى نفس الحاسب أو حواسب أخرى
2. عدّل ملف `appsettings.json` في كل مجلد ليطابق نفس سلسلة اتصال قاعدة البيانات
3. شغّل ملف `.exe` المعني

## 3. تسجيل الدخول والمصادقة

### تسجيل الدخول
1. شغّل التطبيق
2. أدخل **اسم المستخدم** و**كلمة المرور**
3. انقر **تسجيل الدخول** أو اضغط **Enter**
4. فعّل **تذكرني** لحفظ اسم المستخدم لتسجيل الدخول التالي

### حماية الأمان
- **حماية من التخمين**: يتم قفل الحساب بعد 5 محاولات فاشلة (فترة انتظار 15 دقيقة)
- **سياسة كلمة المرور**: 8 أحرف كحد أدنى مع متطلبات التعقيد
- **تتبع الجلسة**: جميع العمليات مسجّلة مع المستخدم الحالي

### تغيير كلمة المرور
1. انقر على **أيقونة المفتاح** في الشريط الجانبي السفلي
2. أدخل كلمة المرور الحالية
3. أدخل وأكد كلمة المرور الجديدة
4. انقر **تغيير كلمة المرور**

### تبديل اللغة
- انقر على **أيقونة الكرة الأرضية** في الشريط الجانبي السفلي للتبديل بين العربية والإنجليزية
- تتحدث الواجهة فوراً دون إعادة تشغيل

## 4. التطبيق الرئيسي

### 4.1 لوحة المعلومات

توفر لوحة المعلومات نظرة عامة فورية على عمليات صالتك:

| البطاقة | الوصف |
|---------|-------|
| **إجمالي الأجهزة** | عدد أجهزة التحكم بالوصول المسجلة |
| **الأجهزة المتصلة** | الأجهزة المتصلة حالياً والمستجيبة |
| **إجمالي الأبواب** | عدد الأبواب المُعدّة عبر جميع الأجهزة |
| **أحداث اليوم** | أحداث الوصول المسجلة اليوم |
| **التنبيهات النشطة** | حالات التنبيه الحالية |

- **الأحداث الأخيرة**: يعرض آخر 20 حدث وصول مع اسم الباب، رقم البطاقة، نوع الحدث، والطابع الزمني
- **حالة الأبواب**: يعرض جميع الأبواب مع حالة القفل/الفتح الحالية
- انقر **تحديث** لتحديث جميع الإحصائيات

### 4.2 إدارة الأجهزة

إدارة أجهزة التحكم بالوصول.

#### إضافة جهاز
1. انقر **إضافة جهاز**
2. أدخل تفاصيل الجهاز:
   - **الاسم**: اسم مألوف (مثال: "المدخل الرئيسي")
   - **عنوان IP**: عنوان الجهاز على الشبكة
   - **المنفذ**: منفذ الاتصال (الافتراضي: 8000)
   - **اسم المستخدم/كلمة المرور**: بيانات اعتماد الجهاز
3. انقر **حفظ**

#### اكتشاف الشبكة
1. انقر **بحث في الشبكة** لاكتشاف الأجهزة تلقائياً على شبكتك المحلية
2. ستظهر الأجهزة المكتشفة في القائمة
3. حدد وأضف الأجهزة إلى نظامك

#### الاتصال بجهاز
1. حدد جهازاً من القائمة
2. انقر **اتصال** لإنشاء الاتصال
3. مؤشر الحالة سيظهر أخضر (متصل) أو أحمر (غير متصل)

#### تحميل سجلات الأحداث
1. حدد جهازاً متصلاً
2. انقر **تحميل السجلات**
3. يتحقق النظام من اتصال الجهاز أولاً
4. حدد الفترة الزمنية لتحميل السجلات
5. يتم تحميل الأحداث وحفظها في قاعدة البيانات
6. يظهر مربع حوار بالملخص يوضح عدد السجلات المستوردة

### 4.3 إدارة الأبواب

تكوين الأبواب المرتبطة بأجهزة التحكم بالوصول.

#### إضافة باب
1. انقر **إضافة باب**
2. حدد **الجهاز الأصل**
3. أدخل تفاصيل الباب:
   - **الاسم**: اسم الباب (مثال: "الباب الأمامي"، "غرفة كبار الشخصيات")
   - **رقم الباب**: رقم الباب الفعلي على الجهاز (1-4)
4. انقر **حفظ**

### 4.4 إدارة اللاعبين

جوهر العمليات اليومية - إدارة أعضاء الصالة وبطاقات الوصول الخاصة بهم.

#### إضافة لاعب جديد
1. انقر **إضافة لاعب**
2. املأ تفاصيل اللاعب:
   - **الاسم الكامل (EN)**: الاسم بالإنجليزية
   - **الاسم الكامل (AR)**: الاسم بالعربية
   - **الهاتف**: رقم الاتصال
   - **رقم البطاقة**: رقم بطاقة/هوية العضو
   - **نوع الاشتراك**: اختر من الخطط المُعدّة
   - **المدة**: أشهر أو أيام مخصصة
   - **الرسوم / المبلغ المدفوع**: تكلفة الاشتراك والمبلغ المستلم
   - **الصورة**: رفع صورة اللاعب (اختياري)
3. انقر **حفظ**

#### تعيين بطاقة وصول
1. حدد لاعباً من القائمة
2. انقر **تعيين بطاقة**
3. أدخل تفاصيل البطاقة:
   - **رقم البطاقة**: رقم البطاقة الفعلية
   - **صلاحيات الأبواب**: حدد الأبواب التي يمكن للبطاقة الوصول إليها
   - **أوقات الفعالية**: جدول الوصول
4. حدد **الأجهزة المستهدفة** لمزامنة البطاقة معها
5. يتحقق النظام من اتصال الأجهزة قبل المزامنة
6. انقر **تعيين** للحفظ والمزامنة

#### تجديد الاشتراك
1. حدد لاعباً
2. انقر **تجديد**
3. اختر:
   - **نوع الاشتراك**: خطة جديدة أو نفس الخطة
   - **المدة**: أشهر أو أيام مخصصة
   - **الرسوم / المبلغ المدفوع**
   - **صلاحيات الأبواب**: تحديث إذا لزم الأمر
4. حدد الأجهزة لمزامنة صلاحية البطاقة المحدّثة
5. انقر **تجديد**
6. يتم إنشاء إيصال للمعاملة

#### تجميد لاعب
1. حدد لاعباً
2. انقر **تجميد**
3. أدخل **سبب التجميد** (مثال: "سفر"، "طبي")
4. يتم إيقاف اشتراك اللاعب مؤقتاً
5. يتم تعطيل البطاقات على أجهزة التحكم
6. عند إلغاء التجميد، تُضاف أيام الاشتراك المتبقية تلقائياً

#### إلغاء تجميد لاعب
1. حدد لاعباً مجمّداً
2. انقر **إلغاء التجميد**
3. أكد العملية
4. يتم تمديد تاريخ انتهاء الاشتراك بمدة التجميد
5. يتم إعادة تفعيل البطاقات على أجهزة التحكم

#### العمليات الجماعية
1. انقر **العمليات الجماعية**
2. حدد نوع العملية:
   - **تجميد الكل**: تجميد عدة لاعبين دفعة واحدة
   - **إلغاء تجميد الكل**: إلغاء تجميد عدة لاعبين
   - **تمديد الاشتراك**: إضافة أيام لعدة لاعبين
3. حدد المجموعة المستهدفة:
   - جميع اللاعبين النشطين
   - المنتهية خلال 7 أيام
   - المنتهية خلال 30 يوماً
   - القائمة المصفّاة حالياً
4. أكد ونفّذ

#### تصفية اللاعبين
استخدم رقائق التصفية في الأعلى:
- **الكل**: عرض جميع اللاعبين
- **قارب على الانتهاء**: اللاعبون الذين ينتهي اشتراكهم خلال 7 أيام
- **المجدّدون**: اللاعبون المجدّدون حديثاً
- **المجمّدون**: اللاعبون المجمّدون حالياً
- **المنتهون**: الاشتراكات المنتهية

استخدم **شريط البحث** للبحث عن اللاعبين بالاسم أو رقم البطاقة أو الهاتف أو نوع الاشتراك.

### 4.5 أحداث الوصول

عرض وإدارة أحداث الوصول من جميع الأجهزة.

#### عرض الأحداث
- تعرض الأحداث: الطابع الزمني، اسم الباب، رقم البطاقة، نوع الحدث، الوصف
- استخدم **الترقيم** للتصفح عبر قوائم الأحداث الكبيرة (100 لكل صفحة)

#### تصفية الأحداث
- **حسب النوع**: إجراء البطاقة، زر، مستشعر الباب، برمجي، تنبيه، نظام
- **حسب الجهاز**: حدد جهازاً محدداً
- **حسب الفترة**: اليوم، أمس، هذا الأسبوع، الأسبوع الماضي، هذا الشهر، الشهر الماضي، آخر 3/6 أشهر، هذا العام

#### تحميل سجلات الجهاز
1. حدد جهازاً من القائمة المنسدلة
2. انقر **تحميل السجلات**
3. حدد الفترة الزمنية
4. يقوم النظام بتحميل الأحداث مباشرة من جهاز التحكم

### 4.6 المالية

تتبع الصحة المالية لصالتك.

#### النظرة العامة
- **إجمالي الإيرادات**: جميع الدخل في الفترة المحددة
- **إجمالي المصروفات**: جميع المصروفات في الفترة المحددة
- **صافي الربح**: الإيرادات ناقص المصروفات
- **الأرصدة غير المدفوعة**: مدفوعات الاشتراك المستحقة

#### المعاملات الأخيرة
- يعرض أحدث المعاملات مع النوع والفئة والمبلغ والتاريخ
- تصفية حسب الفترة (اليوم، هذا الأسبوع، هذا الشهر، إلخ)
- البحث بالوصف أو اسم اللاعب

#### الأرصدة المستحقة
- يسرد اللاعبين الذين لديهم أرصدة اشتراك غير مدفوعة
- يعرض: اسم اللاعب، رسوم الاشتراك، المبلغ المدفوع، الرصيد المتبقي
- انقر **دفع** لتسجيل دفعة جزئية أو كاملة

### 4.7 التدفق النقدي

إدارة معاملات الدخل والمصروفات اليومية.

#### إضافة دخل
1. انقر **إضافة دخل**
2. حدد **الفئة** (اشتراك، مبيعات، إيداع المالك، أخرى)
3. أدخل **المبلغ** و**الوصف**
4. حدد **طريقة الدفع**
5. انقر **حفظ**

#### إضافة مصروف
1. انقر **إضافة مصروف**
2. حدد **الفئة** (إيجار، كهرباء، ماء، رواتب، معدات، إلخ)
3. أدخل **المبلغ** و**الوصف**
4. انقر **حفظ**

### 4.8 تصاريح QR

إنشاء تصاريح QR مؤقتة للزوار اليوميين.

#### إنشاء تصريح QR
1. انقر **إنشاء تصريح**
2. أدخل تفاصيل الزائر:
   - **اسم اللاعب**: اسم الزائر
   - **الهاتف**: رقم الاتصال
   - **الرسوم**: مبلغ رسوم التصريح
   - **الحد الأقصى للاستخدام**: الحد الأقصى لعدد الدخول (الافتراضي: 5)
   - **أيام الصلاحية**: عدد الأيام التي يكون فيها التصريح نشطاً
   - **الجهاز/الباب**: حدد الجهاز والباب للوصول
3. انقر **إنشاء**
4. يتم إنشاء رمز QR وعرضه

#### عرض رمز QR
- يمكن طباعة رمز QR أو حفظه
- شاركه مع الزائر للمسح عند المدخل
- رمز التصريح فريد ومقاوم للتلاعب

#### مسح تصاريح QR
- عند المدخل، تقبل **نافذة مسح QR** إدخال الماسح الضوئي
- يتحقق النظام من: رمز التصريح، تاريخ الانتهاء، الاستخدامات المتبقية
- يتم منح أو رفض الوصول مع ملاحظات بصرية

### 4.9 شاشة المراقبة

عرض أحداث الوصول في الوقت الفعلي على شاشة ثانوية (مثل تلفزيون المدخل).

#### الإعداد
1. وصّل شاشة ثانوية/تلفزيون بحاسبك
2. انقر **المراقبة** في الشريط الجانبي
3. تكتشف نافذة المراقبة تلقائياً الشاشة الثانوية وتتموضع عليها
4. تعرض: صورة اللاعب، الاسم، حالة الوصول، الطابع الزمني

#### أدوات التحكم
- **بدء/إيقاف**: تبديل المراقبة في الوقت الفعلي
- **وضع العرض**: تحسين العرض للإسقاط
- **ملء الشاشة**: تبديل وضع ملء الشاشة

### 4.10 السجلات والتدقيق

عرض سجلات نشاط الجلسة.

- يتم تسجيل جميع العمليات: إنشاء، تحديث، حذف، تجميد، إلغاء تجميد، تجديد، تعيين بطاقة، إزالة بطاقة، مزامنة بطاقة
- يتضمن كل إدخال: الطابع الزمني، العملية، الكيان، المستخدم
- تُخزن السجلات في `Logs/session.log`
- تُعاد تعيين سجلات الجلسة عند كل إعادة تشغيل للتطبيق

### 4.11 السجلات المحذوفة

عرض وإدارة اللاعبين المحذوفين مبدئياً.

#### عرض السجلات المحذوفة
- يعرض جميع اللاعبين الذين تم حذفهم مبدئياً (لم يُزالوا نهائياً)
- يعرض: اسم اللاعب، تاريخ الحذف، حذف بواسطة، السبب

#### استعادة سجل
1. حدد لاعباً محذوفاً
2. انقر **استعادة**
3. يتم استعادة اللاعب إلى الحالة النشطة

### 4.12 ترحيل البيانات

استيراد وتصدير البيانات بين نسخ AccessControlPro.

1. انقر **ترحيل البيانات** في الشريط الجانبي
2. اختر **استيراد** أو **تصدير**
3. حدد الجداول للترحيل
4. اتبع المعالج لإكمال النقل

## 5. لوحة الإدارة

توفر لوحة الإدارة إدارة على مستوى النظام.

### 5.1 إدارة المستخدمين

إدارة مستخدمي النظام وصلاحياتهم.

#### إنشاء مستخدم
1. اذهب إلى **المستخدمون**
2. انقر **إضافة مستخدم**
3. أدخل: اسم المستخدم، كلمة المرور، البريد الإلكتروني
4. عيّن **الصلاحيات** لكل تطبيق:

**صلاحيات التطبيق الرئيسي:**
| الصلاحية | الوصف |
|----------|-------|
| لوحة المعلومات | عرض لوحة المعلومات |
| الأجهزة | عرض الأجهزة |
| إضافة/تعديل/حذف/اتصال أجهزة | إدارة الأجهزة |
| الأبواب | عرض الأبواب |
| إضافة/تعديل/حذف أبواب | إدارة الأبواب |
| اللاعبون | عرض اللاعبين |
| إضافة/تعديل/حذف لاعبين | إدارة اللاعبين |
| تعيين/إزالة بطاقة | عمليات البطاقات |
| تجميد/تجديد | عمليات الاشتراك |
| تقارير اللاعبين | تقارير اللاعبين |
| الأحداث | عرض الأحداث |
| المالية/التدفق النقدي | الوصول المالي |
| إدارة المالية/التدفق النقدي | التعديلات المالية |
| السجلات/المحذوفات | عرض السجلات/المحذوفات |
| المراقبة | شاشة المراقبة |
| تصاريح QR | إدارة تصاريح QR |

5. انقر **حفظ**

#### تعديل الصلاحيات
1. حدد مستخدماً
2. انقر **تعديل**
3. عدّل الصلاحيات حسب الحاجة
4. انقر **حفظ**

### 5.2 الفئات والمنتجات

#### إدارة الفئات
- إضافة فئات المنتجات (مشروبات، مكملات، ملابس رياضية، إكسسوارات، إلخ)
- تُستخدم الفئات في نقطة البيع لتنظيم المنتجات
- لكل فئة اسم بالعربية والإنجليزية

#### إدارة المنتجات
1. اذهب إلى **المنتجات**
2. انقر **إضافة منتج**
3. أدخل:
   - **الاسم (EN/AR)**: اسم المنتج بكلتا اللغتين
   - **الباركود**: باركود المنتج (اختياري، يجب أن يكون فريداً)
   - **السعر**: سعر البيع
   - **الفئة**: فئة المنتج
   - **المخزون**: كمية المخزون الأولية
4. انقر **حفظ**

### 5.3 الموردون وأوامر الشراء

#### إدارة الموردين
1. اذهب إلى **الموردون**
2. انقر **إضافة مورد**
3. أدخل: الاسم، الهاتف، العنوان، جهة الاتصال
4. انقر **حفظ**

#### إنشاء أوامر الشراء
1. اذهب إلى **أوامر الشراء**
2. انقر **طلب جديد**
3. حدد **المورد**
4. أضف المنتجات مع الكميات وتكاليف الوحدة
5. حدد **الخصم** (إن وجد) و**المبلغ المدفوع**
6. انقر **إنشاء**
7. يتم تحديث المخزون تلقائياً لكل منتج
8. يتم إنشاء معاملة مصروفات تلقائياً

#### تتبع المدفوعات
- تتبع أوامر الشراء: الإجمالي، الخصم، المبلغ المدفوع، الحالة (مدفوع/جزئي/غير مدفوع)
- أجرِ مدفوعات إضافية بالنقر على **دفع** في أمر الشراء

### 5.4 التقارير

إنشاء تقارير أعمال مع تصفية حسب التاريخ:
- **تقارير العضوية**: اللاعبون النشطون، المنتهون، المجمّدون
- **التقارير المالية**: الإيرادات، المصروفات، الأرباح حسب الفترة
- **تقارير الحضور**: أحداث الوصول حسب اللاعب/الباب
- **تقارير الأجهزة**: وقت تشغيل الجهاز وعدد الأحداث

### 5.5 سجل التدقيق

عرض جميع الأحداث المتعلقة بالأمان:
- تسجيلات دخول/خروج المستخدمين
- تعديلات البيانات (إنشاء، تحديث، حذف)
- تغييرات الصلاحيات
- عمليات البطاقات
- اتصالات الأجهزة
- تصفية حسب التاريخ والمستخدم ونوع الإجراء

### 5.6 النسخ الاحتياطي والاستعادة

#### إنشاء نسخة احتياطية
1. اذهب إلى **النسخ الاحتياطي**
2. انقر **إنشاء نسخة احتياطية**
3. يتم نسخ قاعدة البيانات احتياطياً إلى الموقع المُعدّ
4. يتضمن اسم ملف النسخة الاحتياطية الطابع الزمني

#### الاستعادة من نسخة احتياطية
1. حدد نسخة احتياطية من القائمة
2. انقر **استعادة**
3. أكد الاستعادة (سيتم استبدال البيانات الحالية)

### 5.7 الإعدادات

تكوين إعدادات النظام:
- **اسم الصالة / اسم الشركة**: يُعرض في التقارير
- **رمز العملة**: يُستخدم في جميع العروض المالية
- **الشعار**: شعارات الصالة والمطور
- **العنوان / الهاتف**: معلومات الاتصال
- **سياسة كلمة المرور**: الحد الأدنى للطول ومتطلبات التعقيد

## 6. نقطة البيع

نقطة البيع لمبيعات المنتجات.

### 6.1 بيع المنتجات

#### بيع سريع
1. تصفح المنتجات حسب **علامات الفئات** على الجانب الأيسر
2. انقر على منتج لإضافته إلى السلة
3. عدّل **الكمية** في السلة إذا لزم الأمر
4. انقر **إتمام الشراء**
5. حدد **طريقة الدفع**:
   - **نقداً**: دفع نقدي مباشر
   - **رصيد البطاقة**: خصم من رصيد بطاقة اللاعب
6. أكد البيع
7. يتم خصم المخزون تلقائياً
8. يتم تسجيل المعاملة

#### إدارة السلة
- **إزالة عنصر**: انقر زر X بجانب العنصر
- **تغيير الكمية**: عدّل حقل الكمية مباشرة
- **تفريغ السلة**: إزالة جميع العناصر دفعة واحدة
- **الإجمالي**: يُحسب تلقائياً عند إضافة/إزالة العناصر

### 6.2 رصيد البطاقة والشحن

#### التحقق من الرصيد
1. ابحث عن لاعب بالاسم في شريط البحث
2. يُعرض رصيد بطاقة اللاعب
3. يظهر الرصيد بالعملة المحددة

#### شحن الرصيد
1. ابحث وحدد لاعباً
2. انقر **شحن**
3. أدخل مبلغ الشحن
4. أكد الدفع
5. يتم تحديث الرصيد فوراً
6. يتم تسجيل معاملة دخل

### 6.3 ماسح الباركود

- وصّل ماسح باركود USB بحاسب نقطة البيع
- امسح أي باركود منتج
- يتم العثور على المنتج تلقائياً وإضافته إلى السلة
- إذا لم يُعثر على الباركود، تظهر رسالة خطأ

#### مبيعات اليوم
- يعرض الشريط العلوي إجمالي عدد مبيعات اليوم ومبلغها
- انقر **تحديث** لتحديث الأرقام

## 7. تفعيل الترخيص

### التفعيل لأول مرة
1. عند التشغيل الأول، تظهر **نافذة التفعيل**
2. يُعرض **معرّف الجهاز** الخاص بك (فريد لحاسبك)
3. تواصل مع مزود البرنامج مع معرّف جهازك
4. أدخل **رمز التفعيل** المُقدّم
5. انقر **تفعيل**

### صلاحية الترخيص
- الترخيص مرتبط بجهازك المحدد (مبني على العتاد)
- يظهر تحذير قبل 15 يوماً من انتهاء الترخيص
- تواصل مع مزودك لتجديد الترخيص قبل انتهائه

## 9. استكشاف الأخطاء وإصلاحها

### لا يمكن الاتصال بقاعدة البيانات
- تحقق من أن SQL Server يعمل
- تحقق من سلسلة الاتصال في `appsettings.json`
- تأكد أن SQL Server يسمح باتصالات TCP/IP
- تحقق من إعدادات جدار الحماية للمنفذ 1433

### الجهاز لا يتصل
- تحقق من أن الجهاز مشغّل وعلى نفس الشبكة
- تحقق من عنوان IP والمنفذ في إعدادات الجهاز
- تأكد من عدم حظر جدار الحماية لمنفذ الجهاز
- جرب ميزة **بحث في الشبكة** لإعادة اكتشاف الأجهزة

### البطاقة لا تتزامن مع الجهاز
- تحقق من أن الجهاز **متصل** (مؤشر أخضر)
- تحقق من صحة رقم البطاقة
- تأكد من تحديد الجهاز كهدف للمزامنة
- تحقق من محدد المعدل (الحد الأقصى 100 عملية في الدقيقة لكل جهاز)

### نسيت كلمة مرور المدير
- تواصل مع مسؤول النظام أو مزود البرنامج
- إعادة تعيين كلمة المرور تتطلب الوصول المباشر لقاعدة البيانات

### تعطل التطبيق
- تحقق من ملف `crash_log.txt` في مجلد التطبيق
- تحقق من `Logs/session.log` للتفاصيل على مستوى العمليات
- تأكد من إمكانية الوصول إلى SQL Server
- تحقق من كفاية مساحة القرص والذاكرة

### مشاكل الترخيص
- تأكد من عدم تغيير عتاد الجهاز بشكل كبير
- تواصل مع المزود مع معرّف جهازك الحالي
- الترخيص مرتبط بالعتاد ولا يمكن نقله بدون مفتاح جديد
